# 量产架构基线

本文件定义必须满足的架构约束，不代表当前仓库已通过量产验证。实现状态见 [status.md](status.md)。

## 部署边界

- Linux 非实时域：AI/规划、网络、OTA 编排、日志汇总、参数管理与产测工具。
- MCU 实时安全域：固定周期采样与控制、限制检查、故障锁存、执行器输出、控制心跳。
- 两域只通过版本化、有界、可超时的消息接口交互；不得共享运行时内部状态或裸指针。
- OSAL 替换操作系统；HAL/设备接口替换设备能力；BSP/总线驱动替换芯片与引脚。

## 不可妥协约束

1. 控制周期不做网络等待、文件系统、动态分配、格式化日志或固件擦写。
2. 命令必须携带版本、设备 ID、序列、有效期和长度/完整性校验；失联后执行明确安全动作。
3. 设备契约必须声明能力、单位、时间戳、数据有效期、错误码、阻塞规则和禁能语义。
4. Linux 故障、升级、重启不能使 MCU 继续执行过期命令。
5. 急停、STO、过流与硬件看门狗形成独立安全链；软件 fault 不是硬件断能的替代。
6. OTA 只写非活动槽；签名、版本、硬件兼容、试启动确认、掉电恢复和回滚必须由测试证明。
7. 参数、标定、固件、硬件版本、产测结果和复位原因必须可追溯。
8. 仿真验证、目标板验证和产测分别记录，不得用动画或单元测试替代硬件验证。

## 发布门禁

| 门禁 | 必须提交的证据 |
|---|---|
| OS/BSP 端口 | 时钟、周期抖动、栈/RAM/CPU、并发与超时测试 |
| 执行器驱动 | 单位/范围、限位、断线、禁能延迟、驱动故障测试 |
| OTA | 损坏镜像、错误签名、版本不兼容、各阶段断电、试启动失败与回滚测试 |
| 参数/存储 | CRC、双备份、版本迁移、写入中断、寿命预算 |
| 安全链 | 急停/STO/过流/看门狗实测与故障传播记录 |
| 产测 | 序列号、硬件版本、标定、通信与执行器结果、可导出报告 |
| 发布 | 固定工具链、依赖版本、构建 ID、制品哈希、测试报告与灰度/回退方案 |

未通过门禁的实现可以用于研发仿真，不得作为量产发布版本。具体指标需由目标硬件、机构风险和产品要求冻结后执行。
